## Found, and left for M2

- **Hydra lists `plain` in `code_challenge_methods_supported`, and passes authorize requests that use `plain` or no PKCE on to the login page.** Hydra applies the PKCE rules when it issues the code, after login and consent, so this cannot be checked until M2 builds the login and consent handlers. M2's end-to-end tests must show that `plain` and a missing `code_challenge` are both refused at that point, with `oauth2.pkce.enforced: true`.
- **The app image was built here from a scratch copy of the repository that added this container's proxy certificate,** because `npm ci` inside `docker build` could not otherwise reach the npm registry from this container. The committed `Dockerfile` was not changed. CI builds it unmodified.
