Health's new `accounts:readiness 14`, run before step 6, read only Health's own database. With five people in the rehearsal, it printed:

- 5 active accounts: 4 signed in with a Health password, 1 with Accounts;
- 3 never signed in with Accounts yet;

That matches the rehearsal: A and D moved, B and C imported but not moved, E never imported.

**Found:** the first run counted D, who signed up *through* Accounts, as "linked but not moved". Health now records the first Accounts sign-in when an account is made through Accounts too. Health's sign-up test checks it.
